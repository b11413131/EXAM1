# STM32G474RE 密碼門鎖與防盜噴霧系統

本專題以 **STM32G474RE NUCLEO 開發板** 為控制核心，設計一套結合 UART
密碼驗證、LED
狀態提示、錯誤警報與手動噴霧輸出的門口安全裝置。使用者可透過電腦終端機輸入密碼；若密碼錯誤累計達
3 次，系統會啟動紅燈警報。另設置實體按鈕，按下後啟動噴霧輸出 3 秒。

> 本專題為功能展示原型。PC5
> 僅提供控制訊號，實際噴霧器或其他負載必須透過適當的驅動電路／繼電器控制，不可直接由
> MCU GPIO 腳位供電。

## 1. 情境故事：誰、在哪裡、遇到什麼麻煩？

-   **誰：** 居住者與未經允許、試圖開門的人。
-   **在哪裡：** 住宅或房間入口。
-   **遇到的麻煩：**
    居住者不在門口時，可能有人嘗試猜測密碼或擅自開門；若沒有即時提示，使用者不容易察覺異常。
-   **設計目標：**
    透過密碼驗證管理門鎖狀態，並在多次輸入錯誤時提供視覺警報；必要時可由使用者按下按鈕啟動噴霧輸出。

## 2. 替身對照：故事中的情境如何對應到實際裝置？

  故事情境               實際裝置／功能
  ---------------------- --------------------------------------------------
  使用者在門口輸入密碼   電腦終端機透過 UART 傳送密碼
  密碼正確               PC8 綠色 LED 亮起 2 秒，終端機顯示 `OK`
  密碼輸入錯誤           終端機顯示 `Wrong`，錯誤次數累計
  連續累計錯誤達 3 次    PC9 紅色 LED 閃爍 3 秒，終端機顯示 `Alarm!`
  使用者需要啟動防護     按下 PC6 按鈕，PC5 輸出啟動 3 秒
  使用者想更換密碼       在終端機輸入 `RESET`，依序驗證舊密碼並設定新密碼

  -------------------------------------------------------------------------------------------
  功能                    操作方式                        預期結果

  開機提示                開啟開發板並連接終端機          顯示系統啟動訊息及密碼輸入提示

  正確密碼                輸入目前密碼後按 Enter          顯示 `OK`，PC8 綠燈亮 2 秒

  錯誤密碼                輸入錯誤密碼後按 Enter          顯示 `Wrong`，錯誤次數加 1

  三次錯誤警報            累計輸入錯誤達 3 次             顯示 `Alarm!`，PC9 紅燈閃爍 3
                                                          秒，錯誤計數歸零

  更換密碼                輸入                            驗證舊密碼成功後，顯示
                          `RESET`，再輸入舊密碼及新密碼   `Enter new password:`；完成後顯示

  手動啟動噴霧            按下 PC6 按鈕                   PC5 輸出維持高電位 3 秒後關閉

  按鈕防彈跳              短時間內重複觸發按鈕            透過 200 ms
                                                          間隔判斷，避免短時間重複啟動

### 密碼更換流程

1.  終端機輸入 `RESET` 並按 Enter。
2.  系統顯示 `Enter old password:`。
3.  輸入正確的舊密碼。
4.  系統顯示 `Enter new password:`。
5.  輸入新密碼並按 Enter。
6.  系統顯示 `Password changed`，之後以新密碼進行驗證。

若舊密碼錯誤，系統會返回一般輸入模式並累計一次錯誤。新密碼不可使用保留指令
`RESET`。

## 4. 使用到的技術

-   **STM32 HAL：** 使用 STM32 HAL 函式庫控制
    GPIO、UART、中斷與系統計時。
-   **LPUART1：** 透過 UART 與電腦終端機進行雙向文字通訊。
-   **UART 接收中斷：** 使用 `HAL_UART_Receive_IT()`
    每次接收一個字元，並在接收完成回呼中設定旗標。
-   **EXTI 外部中斷：** PC6 按鈕使用下降緣觸發，按下時啟動噴霧輸出流程。
-   **GPIO 數位輸出：** 控制 PC5 噴霧訊號、PC8 綠燈與 PC9 紅燈。
-   **非阻塞式計時：** 使用 `HAL_GetTick()` 計算 LED
    與噴霧輸出時間，避免以長時間 `HAL_Delay()` 阻塞主迴圈。
-   **字串處理：** 使用 `strcmp()` 比對密碼與指令，使用 `strcpy()`
    更新目前密碼。

## 5. 腳位表：使用到的每支腳與用途

  STM32 腳位   功能         設定／說明
  ------------ ------------ ----------------------------------------
  PA2          LPUART1_TX   UART 傳送資料
  PA3          LPUART1_RX   UART 接收資料
  PC5          噴霧輸出     一般狀態為 LOW，啟動時 HIGH，持續 3 秒
  PC6          噴霧按鈕     GPIO 外部中斷，下降緣觸發，內部上拉
  PC8          綠色 LED     密碼正確時亮起 2 秒
  PC9          紅色 LED     錯誤累計達 3 次時閃爍 3 秒

**UART 通訊設定**

-   周邊：LPUART1
-   Baud rate：115200
-   Data bits：8
-   Parity：None
-   Stop bits：1
-   Flow control：None

**接線提醒：** UART 與外部裝置須共地，並確認訊號電壓相容。若使用外接
LED，請串接限流電阻。PC5
不可直接驅動噴霧器、馬達或其他大電流負載，應使用符合負載規格的
MOSFET／驅動模組或繼電器，並做好隔離與反向電壓保護。

## 6. 建置與執行

### 開發環境

-   開發板：NUCLEO-G474RE（STM32G474RE）
-   開發工具：STM32CubeIDE／STM32CubeMX（依實際專案環境）
-   程式語言：C
-   函式庫：STM32 HAL Driver
-   電腦端：具備序列埠終端機的電腦

### 操作步驟

1.  使用 STM32CubeIDE 開啟專案。
2.  確認時鐘、LPUART1、GPIO 與 EXTI 設定符合本 README 的腳位表。
3.  將程式編譯並燒錄至 NUCLEO-G474RE。
4.  以 USB 將開發板連接電腦，確認電腦已辨識對應的序列埠。
5.  開啟序列埠終端機，選擇正確的 COM Port，設定為 **115200、8-N-1**。
6.  重置開發板，確認終端機出現啟動訊息。
7.  輸入密碼或 `RESET` 指令，按 Enter 送出。
8.  按下 PC6 按鈕，確認 PC5 輸出狀態。

### 終端機指令範例

``` text
=== Password Lock Ready ===
Enter password (or RESET to change):

1234
OK

RESET
Enter old password:
1234
Enter new password:
5678
Password changed
```

## 7. 程式結構：哪個檔案做什麼？

目前提供的程式主要集中在 `main.c`，可依功能分成以下區塊：

  ---------------------------------------------------------------------------------
  程式區塊／函式                       負責工作
  ------------------------------------ --------------------------------------------
  `USER CODE BEGIN PV`                 宣告密碼、UART
                                       接收緩衝區、錯誤次數、模式與計時變數

  `send()`                             透過 LPUART1 傳送字串至終端機

  `wrong()`                            累計密碼錯誤次數，達 3 次時啟動紅燈警報

  `HAL_UART_RxCpltCallback()`          UART
                                       接收中斷回呼，保存收到的字元並重新啟動接收

  `spray_start_fn()`                   檢查按鈕防彈跳條件並啟動 PC5 輸出

  `HAL_GPIO_EXTI_Falling_Callback()`   新版 HAL 可能使用的 GPIO 下降緣回呼

  `HAL_GPIO_EXTI_Callback()`           HAL GPIO EXTI 通用回呼

  `main()`                             處理 UART 字元、密碼驗證、密碼更換與各項計時

  `SystemClock_Config()`               設定系統時鐘

  `MX_LPUART1_UART_Init()`             初始化 LPUART1 通訊參數

  `MX_GPIO_Init()`                     初始化 LED、噴霧輸出與按鈕腳位

  `Error_Handler()`                    初始化發生錯誤時停止程式執行
  ---------------------------------------------------------------------------------

### 主程式流程

``` text
開機
  |
初始化 HAL、系統時鐘、GPIO、LPUART1
  |
啟動 UART 接收中斷
  |
進入 while(1)
  |
  +--> 收到 UART 字元？
  |       |
  |       +--> Enter：依目前模式執行密碼驗證／更換密碼
  |       |
  |       +--> 一般字元：存入輸入緩衝區
  |
  +--> 綠燈是否已亮滿 2 秒？--> 關閉綠燈
  |
  +--> 紅燈警報是否已達 3 秒？--> 關閉紅燈
  |       否則每 250 ms 切換紅燈狀態
  |
  +--> 噴霧輸出是否已達 3 秒？--> 關閉 PC5
  |
  +--> 回到 while(1)
```

## 10. 已知限制與後續改進

1.  **密碼僅儲存在 RAM：** 目前預設密碼為
    `1234`，更改後若重新開機，密碼會恢復為預設值。可改用 Flash
    或其他非揮發性記憶體保存。
2.  **沒有真正的門鎖致動器：**
    目前程式以綠燈表示密碼正確，尚未控制電磁鎖或馬達。若要實際控制門鎖，需增加驅動電路及安全機制。
3.  **噴霧由按鈕手動啟動：**
    目前沒有人體、入侵或門窗感測器，無法自動判斷入侵事件。
4.  **噴霧輸出為控制訊號：** PC5 只輸出
    HIGH／LOW，實際負載需額外驅動與電源。噴霧介質及使用情境也必須符合安全規範。
5.  **UART 密碼未加密：** 密碼以一般文字透過 UART
    傳送，不適合直接用於高安全性環境。
6.  **輸入緩衝區有限：** 單次輸入最多接收 15
    個字元；目前未加入完整的逾時、清除緩衝區與異常輸入處理。
7.  **三次錯誤只觸發警報：** 警報持續 3
    秒後結束，並不會進入永久鎖定或限制輸入時間。
8.  **HAL EXTI 回呼需確認版本：** 程式同時列出
    `HAL_GPIO_EXTI_Falling_Callback()` 與
    `HAL_GPIO_EXTI_Callback()`。實際使用時應依專案 HAL
    版本確認中斷處理流程，避免重複觸發或未正確呼叫。
9.  **UART 接收旗標可能遺失資料：** 目前使用單一 `rx_data` 與
    `rx_flag`，若主迴圈處理速度跟不上連續接收，可能覆蓋前一個字元；可改用環形緩衝區改善。
